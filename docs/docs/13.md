# 阿里妈妈万相台 竞品调研报告

> 调研时间：2025年7月 | 信息来源：公开报道、阿里妈妈官方资料、财报数据、技术分析

## 一、产品概述

### 1.1 产品定位

万相台是阿里妈妈推出的一站式智能投放平台，定位为商家的"全域AI投放中枢"。其核心理念是将原本分散在多工具中的投放能力整合为统一入口，降低商家操作门槛，实现"一个平台管理全渠道流量"。

产品演进历程：

| 时间      | 里程碑           | 说明                                             |
| --------- | ---------------- | ------------------------------------------------ |
| 2021年    | 万相台上线       | 作为独立智能投放工具首次发布，主打场景化智能投放 |
| 2023年8月 | 万相台无界版发布 | 整合直通车、引力魔方等多款工具，实现"无界"投放   |
| 2024年    | 全站推广上线     | 打通付费与免费流量，引入自然流量协同机制         |
| 2025年2月 | 万相台AI无界升级 | 全面引入AI能力，以AI驱动商家高质增长             |
| 2025年9月 | 万相台AI无界新版 | 为双11百万商家提供24小时智能投放服务             |
| 2026年3月 | "AI万相"发布     | 首创多Agent协同工作流，发布超级经营智能体引擎    |

### 1.2 与阿里妈妈其他产品的关系

万相台经历了从"独立工具"到"整合平台"的演变。2023年万相台无界版发布后，实质上整合并替代了以下独立产品：

- 直通车（搜索竞价推广）→ 整合为万相台中的"关键词推广"场景
- 引力魔方（推荐信息流推广）→ 整合为万相台中的"人群推广"场景
- 超级推荐/品销宝（品牌展示类广告）→ 整合为万相台品牌及内容推广场景

当前阿里妈妈产品矩阵形成"百灵 + 万相台AI无界"双核架构：

- 百灵：侧重品牌广告投放，服务品牌曝光与心智建设
- 万相台AI无界：侧重效果广告投放，覆盖搜索、推荐、全域投放
- 达摩盘：底层人群数据平台，为万相台和百灵提供人群圈选与洞察能力
- 全站推广：万相台内的核心功能模块，打通付费与自然流量

## 二、核心功能

### 2.1 智能投放

#### 跨渠道智能出价

万相台AI无界将搜索、短视频、直播、推荐信息流、站外投放等五大投放场景统一融合，商家只需设定预算和目标ROI，系统自动在各渠道间分配预算并优化出价。

核心能力：

- 统一投放底座：打破原直通车、引力魔方等工具的数据割裂，实现预算与数据的统一看板管理
- 自动出价决策：经历四代技术演进（详见第三章），支持商家设定目标后系统全自动出价
- 多场景组合投放：支持"拉新快""会员快""货品加速"等预设场景，商家可按需组合

#### 全站推广（2024年重点产品）

全站推广是万相台内打通付费与自然流量的核心功能：

- 流量协同机制：系统在商家打爆商品时，按 10%~40% 的比例补充自然曝光
- 确定性ROI：以实际订单转化作为扣费依据，大幅压缩资金结算周期
- 效果数据：2024年618期间，超150万件货品通过全站推广实现销量激增，上线一周后GMV均值提升 65%

### 2.2 人群运营

#### AIPL 人群模型

阿里妈妈经典的消费者运营框架，将消费者分为四个阶段：

- A（Awareness 认知）：被广告触达的消费者
- I（Interest 兴趣）：产生点击、浏览等兴趣行为的消费者
- P（Purchase 购买）：完成购买的消费者
- L（Loyalty 忠诚）：复购或成为会员的消费者

#### DEEPLINK 人群运营模型（AIPL升级版）

DEEPLINK是AIPL的进阶版，将消费者旅程细化为7个阶段，构建了更精细的数字营销指标体系：

| 阶段     | 含义                                       | 时间窗口 |
| -------- | ------------------------------------------ | -------- |
| D - 发现 | 被动接收品牌曝光或产生点击                 | 半个月   |
| E - 种草 | 通过图文视频等内容渠道接触，浏览店铺与商品 | 半个月   |
| E - 互动 | 主动进行关注、订阅等常规交互               | 半个月   |
| P - 行动 | 发生入会、收藏、加购物车等深度行为         | 半个月   |
| I - 首购 | 新客首次购买                               | 两年半   |
| N - 复购 | 非会员身份的多次消费及好评用户             | 一年     |
| L - 至爱 | 会员身份的多次消费及好评用户               | 一年     |

人群资产运营方法：

1. 资产分布洞察：识别各生命周期阶段的受众画像，直接圈选特定群体进行精准投放
2. 流转状态追踪：监测受众在不同阶段的迁移轨迹，评估各渠道贡献占比
3. 全域数据融合：整合品牌自有数据与淘系内外触点资源，通过多方数据打通赋能二次触达

#### 达摩盘（DMP）

达摩盘是阿里妈妈的底层人群数据管理平台，为万相台提供人群圈选能力：

- 支持标签化人群圈选，覆盖淘系全域用户行为数据
- 支持品牌自有数据与平台数据融合（CDP沉淀）
- 提供站外投放数据回流与二次触达能力

### 2.3 创意优化

#### AIGC 创意工具体系

阿里妈妈构建了完整的AIGC创意工具矩阵：

1. 图片创意生成

- 一键换背景、换元素、换布局，低成本生成高质量商品图
- 智能推荐最优模板，自动生成匹配图文
- 虚拟试穿/试戴功能

2. 视频创意生成

- 图生视频：自研视频生成模型，将静态图片转为动态视频
- 解说视频：AI分析热门脚本结构，自动生成配音文案并匹配素材，批量生产30秒+解说短视频
- 即刻成片：一键生成短视频广告素材

3. 文案创意生成

- 基于人群画像和历史投放数据预测消费者偏好
- 生成针对特定人群和促销场景的高度个性化营销文案

4. 效果数据（2025年双11）

- AIGC工具累计产出近 2亿份 营销物料
- 即刻成片功能：点击率提升 40%，有效观看提升 90%，转化效率提升 100%+
- 每日服务超 120万 商家

### 2.4 数据洞察

#### 全链路数据看板

- 全链路自动归因：追踪从种草到成交的完整数据链路
- 智能预算调优：每日自动核算并优化出价策略
- 多渠道效果对比：统一看板展示搜索、推荐、内容、站外等各渠道ROI

#### ROI 分析

- 支持分渠道、分场景、分人群的ROI拆解
- 支持长期生意价值归因（不局限于单次成交）
- 站外效果投放核心渠道ROI超 10倍

## 三、技术能力

### 3.1 智能出价模型（四代演进）

阿里妈妈的自动出价技术经历了完整的四代演进，是业界最成熟的广告出价技术体系之一：

#### 第一代：经典控制类

- 基于 PID控制算法，将效果最大化转化为预算消耗控制问题
- 按预设消耗曲线控制预算分配
- 局限：仅在流量价值分布稳定时有效

#### 第二代：规划求解类（LP-based）

- 基于拉格朗日变换构造最优出价公式
- 使用 Online LP 算法进行参数寻优
- 局限：高度依赖对未来流量质与量的精准预估

#### 第三代：强化学习类（RL-based Bidding）

将出价视为动态环境下的序列决策问题，经历三次范式迭代：

- Simulation RL (SRLB)：构建模拟竞价环境训练，设计MDP状态与Reward
- Offline RL-based Bidding：使用线上真实决策日志训练，引入CQL和IQL解决分布外问题
- Online RL (SORL)：基于Q函数Lipschitz光滑特性设计安全探索域，实现在线安全探索

#### 第四代：生成模型类（AIGB - AI Generative Bidding）

- 将出价、优化目标和约束视为联合概率分布
- 转化为 条件分布生成问题，基于历史轨迹数据拟合分布特征
- 优势：避免单步判别的误差累积，适合长序列决策，具备更好的可解释性

#### 补充技术

- Bid Shading：复杂环境下的数据驱动微调出价
- 多智能体联合出价：百万级广告主纳什均衡求解
- Fairness机制：为大小广告主匹配个性化出价策略族
- 两阶段协同出价：粗竞+精竞级联架构的全链路自动出价

### 3.2 CTR/CVR 预估模型

- 在粗竞+精竞两阶段架构中，精竞阶段依赖高精度的 PCVR（预估转化率） 进行流量价值评估
- 阿里妈妈搜索广告预估模型经历了多代迭代（具体模型架构如DIN/DIEN等公开资料有限）
- 粗竞阶段处理百倍于精竞的广告量，对预估准度要求更高

### 3.3 AIGC 能力

#### "AI万相"多Agent协同引擎（2026年3月发布）

以 LMA大模型 为基础，首创多Agent协同工作流：

| Agent    | 名称          | 功能                                         |
| -------- | ------------- | -------------------------------------------- |
| 万相智识 | 意图识别Agent | 实时追踪用户兴趣并匹配商家资源               |
| 万相智品 | 商品理解Agent | 重构产品卖点，将物理属性转化为情绪与场景标签 |
| 万相智造 | 创意生成Agent | 秒级生成千人万面的差异化素材                 |
| 万相智投 | 投放优化Agent | 自动规划投放路径并实时调整策略               |

核心能力：

- 秒级生成"千人万面"的差异化创意素材
- 创意与目标人群意图精准匹配
- 从"根据关键词找流量"转变为"主动链接消费者意图"
- 能力已无缝集成至百灵、万相台等现有产品

#### 万相营造（独立AIGC工具）

- 阿里妈妈官方AI商品图生成与智能试衣工具
- 网址：agi.alimama.com
- 支持商品图背景替换、场景生成、虚拟试穿等

### 3.4 大数据处理能力

#### 实时竞价引擎

- 采用 "粗竞+精竞"两阶段级联架构
- 粗竞阶段处理海量广告（百倍于精竞），快速筛选候选集
- 精竞阶段进行高精度排序与定价
- 支持百万级广告主并发竞价

#### 人群圈选引擎

- 基于达摩盘（DMP）的标签化人群圈选
- 支持淘系全域用户行为数据的实时计算
- 支持品牌CDP数据与平台数据融合
- 支持站外投放数据回流与二次触达

#### 拍卖机制设计

- 从经典GSP/VCG演进至深度学习驱动的拍卖机制
- 落地 Deep GSP（深度网络提升分配能力）、Neural Auction、Two-Stage Auction
- 支持"出价-拍卖"联合设计，适应广告主Agent代竞的新模式

## 五、与淘宝主站的协同关系

### 5.1 流量协同机制

万相台与淘宝主站的关系是"广告投放平台"与"流量生态"的协同：

1. 付费与自然流量打通：全站推广核心机制——系统在商家通过付费流量打爆商品时，按 10%~40% 的比例补充自然搜索和推荐曝光，实现"付费撬动免费"
2. 统一流量分配：淘宝主站的搜索、推荐、信息流等流量池同时服务自然流量和付费流量，万相台作为付费流量的统一入口
3. 全链路数据回流：淘宝主站的用户行为数据（浏览、收藏、加购、成交）实时回流至达摩盘，反哺万相台的人群圈选和出价决策

### 5.2 业务协同模式

- 搜索场景：万相台的关键词推广直接参与淘宝搜索结果页的广告位竞价
- 推荐场景：万相台的人群推广接入淘宝首页信息流、猜你喜欢等推荐位
- 内容场景：万相台支持短视频和直播推广，接入淘宝直播、逛逛等内容频道
- 全站推广：打破付费/免费边界，系统在全站范围内为商品寻找最优流量组合

### 5.3 无界智惠券

2025年推出的新机制：平台加大补贴力度，利用全链路技术精准识别并激活沉睡或犹豫用户，将补贴转化为促进交易的杠杆。该机制与万相台投放能力深度结合，实现"投放+补贴"的联合驱动。
